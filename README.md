# 📊 Data Analysis & Visualization in Python, Tableau & Excel

This repository contains data analysis and visualization projects built using **Python**, **Tableau**, and **Excel**. These projects explore real-world datasets to extract insights, perform statistical analysis, and create compelling visual stories using interactive dashboards.

## 🔍 Features

- ✅ Data cleaning and preprocessing with Python (Pandas, NumPy)  
- 📊 Exploratory Data Analysis (EDA) using Matplotlib, Seaborn, and Plotly  
- 📈 Interactive dashboards and storyboards built in Tableau  
- 📑 Real-world datasets and business case studies  
- 📉 Excel-based visualizations using charts and pivot tables
